# Rock Paper Scissors Game 🪨 📄 ✂️

A classic, interactive Rock Paper Scissors game where a user plays against the computer. This project focuses on DOM manipulation, event handling, and clean UI design using Vanilla JavaScript.

## ✨ Features
* **Interactive Gameplay:** Click on the images to make your move.
* **Smart Logic:** The computer generates a random move to compete against you.
* **Real-time Scoring:** The scoreboard updates instantly after every round.
* **Visual Feedback:** The message bar changes color (Green for Win, Red for Loss, Yellow for Draw) and displays custom messages.
* **Responsive Design:** Styled with CSS Flexbox for a centered and clean layout.

## 🛠️ Technologies Used
* **HTML5:** Structure of the game and scoreboard.
* **CSS3:** Custom styling, hover effects, and layout.
* **JavaScript (ES6+):** Game logic, random move generation, and DOM updates.

## 📂 Project Structure
* `index.html` - The skeleton of the application.
* `style.css` - Visual styling and layout.
* `app.js` - The engine driving the game logic.
* `/images` - Contains assets for Rock, Paper, and Scissors.
